## 功能

- **拍摄任务**：排期、地点、参与人、携带器材，任务状态一目了然
- **器材清单**：分类、在库 / 借出 / 维修状态、领用与归还记录
- **团队协作**：组长、器材管理员、成员角色与邀请码加入
- **客户分享**：任务分享链接、客户提交拍摄需求
- **云端同步**：微信云开发，换设备登录即可继续
